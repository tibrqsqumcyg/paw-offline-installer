# Paw — Free Offline Installer

![Category](https://img.shields.io/badge/API_Client-blue?style=flat-square)

## About

Paw is a premium native macOS API client and REST tool for designing, testing, and documenting HTTP APIs. Features dynamic values with built-in functions, code generation in dozens of languages and frameworks, environment management, and visual JSON/XML response viewing. Paw's native macOS engineering and powerful dynamic value system make it the preferred API tool for Mac developers willing to pay.

## Common Problems & Limitations

- **macOS Only** — No Windows or Linux version
- **Commercial License** — Paid license required
- **Raycast Owner** — Acquired by Raycast; development direction evolving
- **Sync/Team Features** — Collaboration features less developed than cloud-first alternatives
